# Отчёт проверки MSC Multiplayer 0.1.9-dev

## Сделано
- Исправлен жизненный цикл UDP-соединения клиента: receive-поток закреплён за конкретным сокетом и generation ID.
- Улучшена очистка сокета/потока при отключении, тайм-ауте и отказе.
- Добавлена очистка списка удалённых игроков и аватаров после потери связи.
- Исправлена выдача списка существующих игроков новому клиенту.
- Убрана отправка фиктивных ROSTER-координат до первого POS.
- Согласованы ограничения координат.
- Добавлен автоматический UDP smoke-тест.
- Синтаксис Python smoke-теста проверен.

## Не проверено
- C# компиляция: .NET SDK недоступен в среде подготовки.
- Запуск smoke-теста против настоящего C# сервера.
- Совместимость MSCLoader API и загрузка мода.
- F8, модели и синхронизация в реальной игре.

## Проверка на Windows
1. Установить .NET 8 SDK и Python 3.
2. Распаковать архив.
3. Запустить START_HERE.bat, выбрать 1 для сборки сервера.
4. Выбрать 2 для запуска сервера.
5. Во втором окне терминала выполнить:
   `python tools\protocol_smoke_test.py --host 127.0.0.1 --port 27020`
6. Для сборки мода указать MSC_GAME_DIR и выбрать пункт 3.
7. Проверить F8 и подключение двух компьютеров.

Архив не считается протестированным в My Summer Car до выполнения этих проверок.
