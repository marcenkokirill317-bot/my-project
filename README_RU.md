# MSC Multiplayer 0.1.10-dev

Самостоятельный экспериментальный мультиплеер для My Summer Car. Исходники других мультиплеерных модов не используются.

## Этап 1 — подключение и лобби

В этой версии реализованы в исходном коде:

- F8 — открыть/закрыть окно лобби.
- Поля IPv4/домен, UDP-порт и ник (до 20 символов).
- Connect, Cancel во время подключения и Disconnect после подключения.
- Проверка корректности порта и непустого ника.
- Сохранение адреса, порта и ника через Unity PlayerPrefs.
- Статусы подключения, отказа сервера и тайм-аута.
- Проверка heartbeat: клиент отправляет PING каждые 2 секунды и обнаруживает потерю ответа.
- Список до 4 игроков; новые участники появляются в списке у уже подключённых клиентов, выходящие удаляются.
- Сервер принимает настраиваемый UDP-порт через `--port`.

## Запуск сервера на Windows

1. Установи .NET 8 SDK.
2. Открой эту папку в Проводнике.
3. Запусти `START_HERE.bat` и выбери `1` для сборки.
4. Выбери `2` для запуска сервера на UDP 27020.
5. Разреши входящие UDP-подключения к выбранному порту в брандмауэре Windows.

Для другого порта запусти сервер из терминала:

`dotnet run --project src\MSC.Server\MSC.Server.csproj -c Release -- --port 27021`

Игроки должны указать тот же порт в F8. Для игры через интернет владелец сервера должен открыть/пробросить UDP-порт на роутере; автоматический UPnP пока не реализован.

## Сборка клиентского мода

Нужны MSCLoader и DLL из папки `mysummercar_Data\Managed` установленной игры. В версии 0.1.10-dev пункт `3` в `START_HERE.bat` сам запросит путь к корневой папке My Summer Car и проверит наличие трёх библиотек: `MSCLoader.dll`, `UnityEngine.dll`, `Assembly-CSharp.dll`.

Пример пути:

`C:\Program Files (x86)\Steam\steamapps\common\My Summer Car`

Указывай именно корневую папку игры, а не `mysummercar_Data\Managed`. DLL в архив проекта не включены: используются файлы из твоей установки игры.

Можно собрать вручную из командной строки:

`set "MSC_GAME_DIR=C:\Games\Steam\steamapps\common\My Summer Car"`

`dotnet build src\MSC.Client\MSC.Client.csproj -c Release`

Скопируй `MSC.Multiplayer.Client.dll` из `src\MSC.Client\bin\Release\net35` в папку модов MSCLoader согласно структуре твоей установки.

## Исправления 0.1.9-dev

- UDP receive-поток закреплён за конкретным сокетом и поколением соединения, чтобы старый поток не мог читать новый сокет после быстрого переподключения.
- Улучшено закрытие транспорта при тайм-ауте и отказе сервера.
- При потере соединения очищаются устаревшие записи игроков и удалённые модели.
- Новый клиент получает PLAYER_JOIN-записи существующих игроков для списка лобби.
- ROSTER с координатами отправляется только после первого POS от игрока: фиктивные аватары в (0, 0, 0) не создаются.
- Ограничения координат клиента и сервера согласованы.

## Автоматический сетевой тест

После запуска сервера открой второе окно терминала и выполни:

`python tools\\protocol_smoke_test.py --host 127.0.0.1 --port 27020`

Тест проверяет подключение, список игроков, PLAYER_JOIN, лимит в 4 игрока, отказ пятому, рассылку координат, PLAYER_LEAVE и повторное использование освободившегося слота. Нужен Python 3; запуск игры для этого теста не требуется.

## Проверка этапа 1

1. Запусти сервер на первом компьютере.
2. Разреши UDP-порт в брандмауэре.
3. На первом ПК открой игру, нажми F8, введи `127.0.0.1`, порт `27020`, ник и подключись.
4. На втором ПК введи локальный IP первого ПК (или внешний IP при проброшенном порте), тот же порт и другой ник.
5. Убедись, что оба клиента видят обоих игроков в списке.
6. Отключи одного клиента и проверь, что его ник исчез у второго.
7. Проверь неверный порт/недоступный сервер и превышение лимита в 4 подключения.

## Что ещё не подтверждено

- Проект не был собран и запущен в Windows/My Summer Car в этой среде. Поэтому этап 1 нельзя честно объявить протестированным до выполнения проверки выше.
- В клиентском проекте требуются DLL именно твоей версии игры и MSCLoader.
- Только IPv4; IPv6 пока не поддерживается.
- Нет списка публичных серверов, Steam-приглашений и автоматического проброса портов.
- Этап 2 (настоящая модель игрока, анимации, проверенная привязка к игровому объекту) ещё не завершён.

Это dev-сборка для тестирования, не релизная версия.
