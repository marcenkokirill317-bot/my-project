# Отчёт проверки MSC Multiplayer 0.1.9-dev

## Изменение этой версии
Исправлена очистка лобби при неудачном подключении: если клиент успел получить PLAYER_JOIN/ROSTER, но не получил WELCOME, данные теперь очищаются после отказа или тайм-аута. Ранее очистка срабатывала только после уже установленного соединения.

## Унаследованные исправления 0.1.8
- Защита UDP receive-потока от переподключения на другом сокете.
- Обновление списка игроков для новых клиентов.
- Отправка ROSTER только после получения координат игрока.
- Очистка удалённых аватаров после потери связи.
- UDP smoke-тест для проверки сервера.

## Проверки
- Архив 0.1.9-dev упакован и проверен на целостность.
- Синтаксис Python smoke-теста проверен.
- Компиляция C# и запуск в My Summer Car не выполнены: в среде подготовки отсутствуют .NET SDK и сама игра.
