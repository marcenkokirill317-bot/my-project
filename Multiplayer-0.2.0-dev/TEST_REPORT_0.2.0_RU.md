# Отчёт о проверке 0.2.0-dev

## Проверено реально
1. Сервер скомпилирован: Roslyn 4.9.2, net8.0, референсные сборки .NET 8.0.11,
   -langversion:12 -nullable:enable -optimize+. 0 ошибок, 0 предупреждений.
2. Сервер запущен и прогнан по UDP:
   - protocol_smoke_test.py (v1): 7/7 PASS.
   - protocol_v2_test.py: 7/7 PASS (формат ST2, seq, устаревшие пакеты, координаты вне
     диапазона, лимит частоты, совместимость с v1, отключение).
3. Клиент скомпилирован: Roslyn, -langversion:7.3, -nostdlib, референсные сборки .NET Framework 3.5
   плюс стабы UnityEngine/MSCLoader. 0 ошибок, 0 предупреждений. Подтверждает синтаксис,
   типовую согласованность 9 файлов и совместимость с API .NET 3.5.
4. Логика клиента исполнена headless (RemoteMotion + MotionSender с функциональными Vector3/Mathf):
   8/8 PASS - частота 15 Гц, POS2 = 13 полей, разбор ST2 и STATE, отбрасывание NaN и устаревшего seq,
   интерполяция, сброс буфера при телепорте, отсутствие улёта после телепорта.

- Игра не запускалась: поведение ника, моделей и анимаций визуально не проверено.
